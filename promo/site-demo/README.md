# Site demo

Landscape 16:9 demo (1920x1080, 30 fps, 25.5 s, about 2.7 MB) for the figmake-sync product page, built with HyperFrames. The app screens are live HTML/CSS reproductions of the minimal renderer (start, preview, prompt bar, Send to Figma, Sent), with a typing and cursor simulation of: paste link, Open, "Make the button blue", Send to Figma.

Captions: 0:00 Paste your Figma Make link. / 0:05 Describe a change. / 0:09 Your own AI. Not Figma's tokens. / 0:14 Send it back. / 0:20 end card (figmake-sync icon, Sherlabs wordmark, Figma mark, "Unofficial. Not affiliated with Figma.").

Render: `npx hyperframes render --quality high -o r.mp4 && ffmpeg -i r.mp4 -c copy -movflags +faststart demo.mp4`. Audio is generated by `tools/gen_audio.py assets`. Copy `demo.mp4` and `demo-poster.jpg` to `sherlab-website/public/products/figmake-sync/`.
