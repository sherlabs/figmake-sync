Figma Make lets you iterate on a prototype, but only through Figma's own AI credits, which are limited per seat. The React code is visible in Figma, yet you can only change it by hand.

We built Figmake Sync to get around that. It is a desktop app that pulls the project's code onto your computer, so you can change it with the Claude Code or ChatGPT Codex subscription you already pay for. No Figma AI credits are spent.

New in this release:
- Paste or attach screenshots straight into the chat
- Click any element in the live preview and it becomes a chip (with details and a crop) the AI can see
- Switch models whenever you like
- Sign in to Claude or ChatGPT inside the app
- A collapsible left rail and a Fit button that scales the preview to the window
- Agent activity as a step-by-step timeline, so you can follow what it is doing

And the basics still work: live preview, see exactly what changed (diffs) before anything is sent, then send it back to Figma Make.

It is free. The Windows build is made by CI; we have not tested it on Windows yet.

Figmake Sync is an unofficial tool by Sherlabs. It is not affiliated with or endorsed by Figma.
