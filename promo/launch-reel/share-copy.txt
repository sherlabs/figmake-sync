Figma Make lets you iterate on a prototype, but only through Figma's own AI credits, which are limited per seat. The React code is visible in Figma, yet you can only change it by hand.

We built Figmake Sync to get around that. It is a desktop app that pulls the project's code onto your computer, so you can change it with the Claude Code or ChatGPT Codex subscription you already pay for. No Figma AI credits are spent.

How it works:
- Paste your Figma Make link and the code comes local
- Chat with your own AI: paste screenshots, click any element in the live preview, pick the model, sign in to Claude or ChatGPT inside the app
- Watch the live preview update, and follow the agent step by step
- See exactly what changed (diffs) before anything is sent
- Send it back to Figma Make

It is free.

Figmake Sync is an unofficial tool by Sherlabs. It is not affiliated with or endorsed by Figma.
