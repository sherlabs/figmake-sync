# Brag Plan: figmake-sync

## What is this app?
A Mac and Windows app that pulls a Figma Make project (a real React app) into a local folder so you edit it with your own Claude Code or Codex subscription, then push it back.

## The angle
Problem first. The code is right there inside Figma Make, but you can only change it by hand, or by spending Figma's AI tokens on every tweak. figmake-sync moves it local, so your own subscription does the editing.

## Hook (0-2.5s)
"Every tweak costs tokens." with a credits meter draining as three small requests land.

## Key moments
- "It's your code." Cart.tsx with the buggy reduce line highlighted.
- "Edit it by hand. Or spend tokens." typing caret versus a draining meter.
- "Pull it local." real pull progress crop, Figma mark -> arrow -> figmake-sync icon.
- "Your own subscription. Not Figma's tokens." real Agent card crop (Claude Code, Codex).
- "npm install. Runs locally." real Run it locally crops (localhost:5173, Vite log).
- "Type the change." typed prompt, then real agent stream crop (Read, Edited Cart.tsx, Wrote usePromo.ts).
- "Push it back to Figma Make." zoom to the real Push 3 button, cursor click.

## Outro / punchline
Figma mark -> figmake-sync icon, "Free for Mac & Windows", "by" official Sherlabs wordmark, sherlabs.com, "Unofficial. Not affiliated with Figma."

## User flow worth showing
Pull -> install and run locally -> prompt the agent -> push.
